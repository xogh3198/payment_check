# 안드로이드 설치 안내

## APK 다운로드

1. https://github.com/xogh3198/payment_check/releases 로 이동합니다.
2. 최신 Release의 Assets에서 payment-check.apk를 누릅니다.
3. 내려받은 APK를 실행합니다.
4. 브라우저가 설치를 차단하면 현재 브라우저에 대해서만 알 수 없는 앱 설치를 허용합니다.
5. 설치가 끝나면 해당 허용은 다시 꺼도 됩니다.

이 APK는 초기 검증을 위한 debug 서명 앱입니다. Google Play 배포용 앱이 아니며 내부 테스트 단말에서만 사용합니다.

## 앱 설정

1. 앱을 실행합니다.
2. 알림 접근 설정 열기를 누릅니다.
3. MarketBite 입금 확인 또는 TradLab 입금 알림 감지를 허용합니다.
4. Webhook URL을 입력합니다.
5. 서버가 공유 시크릿을 사용한다면 동일한 값을 입력합니다.
6. 설정 저장을 누릅니다.
7. 은행별 샘플 웹훅 전송으로 연결 상태를 확인합니다.

로컬 Viewer를 사용하는 실제 단말의 Webhook URL 예시:

http://노트북의-로컬-IP:8787/webhook/deposits

단말과 노트북은 같은 Wi-Fi에 있어야 하며 다음 주소가 단말 브라우저에서 열려야 합니다.

http://노트북의-로컬-IP:8787/health

## 실제 입금 알림 테스트

1. 국민은행, 하나은행 또는 농협은행 앱의 입출금 알림을 켭니다.
2. 테스트 계좌로 소액을 입금합니다.
3. 휴대전화에 은행 입금 알림이 표시되는지 확인합니다.
4. MarketBite 입금 확인 앱의 최근 감지 내역을 확인합니다.
5. Viewer 또는 웹훅 서버에서 같은 이벤트가 수신됐는지 확인합니다.

앱은 계좌를 직접 조회하지 않습니다. 휴대전화에 표시된 은행 알림을 입금 후보로 전달하며 최종 입금 확정은 별도 검증이 필요합니다.

## 업데이트 설치

새 Release에서 APK를 다시 내려받아 기존 앱 위에 설치합니다. applicationId와 debug 서명키가 유지되는 동안 앱 데이터와 설정이 유지됩니다.

GitHub Actions 실행 환경의 debug 서명키는 실행마다 달라질 수 있으므로, 업데이트 설치가 거부되면 기존 테스트 앱을 삭제한 뒤 새 APK를 설치해야 합니다. 운영 배포 전에는 고정된 전용 서명키를 사용해야 합니다.
